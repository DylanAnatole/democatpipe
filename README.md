# Cat Pipe – web demo

Chơi ngay trên trình duyệt: **https://dylananatole.github.io/democatpipe/**

Kéo các khối để nối đường cho mèo về hố cùng màu. Hình dạng khối chính là đường đi.
30 màn, có các cơ chế: khối màu, băng, chìa khóa và ổ khóa, cổng, bom, khóa trục, khối bí ẩn, mèo đóng băng, khối một chiều.

Prototype nội bộ (Unity 2022.3, WebGL). Hình ảnh và âm thanh lấy từ game Catdom, chỉ dùng để demo, không phải sản phẩm phát hành.
